# LocalTune

Плеер для локальной музыки, который не пытается быть стриминговым
сервисом. Указываешь папку с треками на своём устройстве — и всё:
обложки, теги, тексты песен, плейлисты и история прослушиваний
работают полностью офлайн, ничего никуда не загружается.

Папка с музыкой запоминается один раз и подхватывается сама при
следующем запуске — выбирать её заново не нужно.

## Возможности

- Чтение тегов из MP3 (ID3) и FLAC (Vorbis Comments): название,
  исполнитель, альбом, жанр, год, обложка
- Синхронизированные тексты песен (`.lrc`)
- Плейлисты, избранное, история и счётчики прослушиваний
- Очередь воспроизведения, шафл, повтор, регулировка скорости
- Кроссфейд между треками и встроенный эквалайзер
- Адаптивный интерфейс — от полноэкранного окна до половины экрана

## Платформы

Один и тот же интерфейс работает на трёх платформах — где меняется
только способ доступа к файлам на диске:

- **Веб** — открывается прямо в браузере 
- **macOS / Windows** — нативное десктоп-приложение
- **Android** — нативное приложение с полным доступом к файлам
  телефона

Готовые сборки — во вкладке **Releases** этого репозитория.
